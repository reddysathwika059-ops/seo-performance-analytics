# SEO Performance Analytics

## Project Overview

This project analyzes SEO performance data using Python and provides insights into keyword performance.

The analysis uses metrics such as:

- Clicks
- Impressions
- Click-Through Rate (CTR)
- Search Position

## Technologies Used

- Python
- Pandas
- Matplotlib
- Excel

## Analysis Performed

The project:

1. Calculates CTR for each keyword.
2. Identifies the best-performing keyword.
3. Identifies the worst-performing keyword.
4. Calculates average CTR.
5. Calculates average search position.
6. Creates a CTR visualization.
7. Exports the analyzed data to an Excel report.

## Key Insights

The analysis helps identify which keywords are performing well and which keywords need SEO improvement.

## Output

The project generates:

- `seo_report.xlsx` — analyzed SEO data
- CTR visualization showing keyword performance
